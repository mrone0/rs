# 三星：Span 可靠后台设置

适用于 Android 13–16 的主流 One UI 版本。三星通常没有单独的“自启动”开关，重点是无障碍、“不受限制”和“从不自动休眠”。

## 1. 开启 Span 无障碍服务

首选方式：打开 Span，点击 **开启可靠后台 > 开启**。

手动路径：

**设置 > 辅助功能 > 已安装的应用 > Span > 开启**。

部分版本会显示为“已安装的服务”。确认系统警告后开启。如果提示“受限设置”：

1. 打开 **设置 > 应用程序 > Span**；
2. 点击右上角 **⋮ > 允许受限设置**；
3. 返回辅助功能页面重试。

## 2. 将电池用量设为“不受限制”

1. 打开 **设置 > 应用程序 > Span > 电池**；
2. 选择 **不受限制**；
3. 回到 Span，点击 **允许后台运行 > 允许**。

若该页面只有“允许后台活动”，请开启它，并在“优化电池使用量”列表中关闭对 Span 的优化。

## 3. 加入“从不自动休眠的应用程序”

1. 打开 **设置 > 电池和设备维护 > 电池 > 后台使用限制**；
2. 进入 **从不自动休眠的应用程序**；
3. 点击 **+**，添加 Span；
4. 同时检查“休眠应用程序”和“深度休眠应用程序”，确保 Span 不在其中。

较新的 One UI 可能把第一段简化为 **设置 > 电池 > 后台使用限制**。三星官方说明，深度休眠应用只有在用户打开后才会运行，而“从不自动休眠”用于排除自动后台限制。

如果 Span 没有出现在可添加列表中，先回到 **应用程序 > Span > 电池**，暂时设为“已优化”，添加到“从不自动休眠”后，再按实际机型决定是否重新设为“不受限制”。部分 One UI 版本会隐藏已经“不受限制”的应用。

## 4. 允许通知和后台数据

1. **设置 > 通知 > 应用通知 > Span**，开启通知；
2. 确保“Span 剪贴板同步”通知类别开启；
3. **设置 > 应用程序 > Span > 移动数据**；
4. 开启“允许后台数据使用”；如果常用流量节省模式，再开启“数据节省程序开启时允许使用数据”。

## 5. 省电模式注意事项

三星省电模式会限制后台网络和应用活动。测试 Span 时先关闭 **设置 > 电池 > 省电**。如果必须长期使用省电模式，应在开启后重新完成锁屏测试；不同 One UI 版本即使设置“不受限制”，仍可能应用全局省电限制。

## 6. 验证

1. 在其他应用复制文本，点击 Span Tile、无障碍快捷入口或通知动作；
2. 确认只显示发送结果，Span 界面不打开；
3. 锁屏 10 分钟，从 PC 执行 `span send "samsung-lock-test"`；
4. 重启手机，不打开 Span，再从 PC 发送；
5. 一天后复查 Span 是否被系统自动加入休眠列表。
