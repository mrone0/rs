# Android 可靠后台设置总览

Span 需要在局域网内持续接收可信设备发送的文本。Android 本身和各厂商的省电策略可能暂停后台服务，因此首次配对后建议完成以下设置。

本文档最后核对于 2026-09-18。厂商可能在系统更新后调整菜单名称；找不到入口时请使用文末的设置搜索关键词。

## 先在 Span 内完成

1. 打开 Span，确认 PC 已显示为“已连接”或“已信任”。
2. 在首页的后台设置卡片上依次处理：
   - **允许后台通知**：Android 13 及以上必须允许，否则无法稳定显示前台接收服务；
   - **开启可靠后台**：系统跳转后，在“已下载的应用”“已安装的服务”或相近页面中找到 Span 并开启；
   - **允许后台运行**：在系统弹窗中选择“允许”。
3. 返回 Span。后台设置卡片消失，表示 Android 通知、无障碍服务和系统电池优化豁免均已就绪。

Span 的无障碍服务不读取屏幕内容、不检查控件、不模拟点击。它只负责在厂商清理普通服务后恢复接收器，并在用户主动点击发送快捷入口时读取一次剪贴板。

## 如果提示“受限设置”

Android 13 及以上可能禁止侧载 APK 直接启用无障碍服务：

1. 打开 **设置 > 应用 > Span**；
2. 点击右上角 **⋮**；
3. 选择 **允许受限设置**，完成锁屏密码或指纹验证；
4. 回到无障碍设置，再开启 Span。

部分厂商会把入口放在“应用信息 > 更多”或“安全设置”中。如果完全没有“允许受限设置”，请先确认 APK 来源可信，再尝试系统自带安装器重新安装。不要为了安装 Span 全局关闭系统安全扫描。

## 设置完成后的验证

建议按顺序完成，不要只测试亮屏前台状态。

### 1. Android → PC

1. 在浏览器或聊天应用中复制一段唯一文本；
2. 不打开 Span，点击无障碍快捷按钮、Quick Settings Tile 或常驻通知中的“发送剪贴板”；
3. 手机应显示“已发送到 1 台设备”等提示，且不应打开 Span 界面；
4. 在 PC 上粘贴并确认文本一致。

### 2. PC → Android

在 PC 执行：

```sh
span send "span-background-test"
```

手机收到通知后，直接进入任意输入框粘贴。无需先打开 Span。

### 3. 锁屏与重启

1. 从最近任务中离开 Span，锁屏 10 分钟后重复双向测试；
2. 重启手机；
3. 不手动打开 Span，等待约 30 秒后从 PC 再发送一次；
4. 若重启后必须打开一次 Span 才恢复，继续完成对应厂商文档中的“自启动/应用启动”设置。

## 通用排查

| 现象 | 优先检查 |
| --- | --- |
| 无障碍开关开启后立刻关闭 | “允许受限设置”、厂商安全中心、工作资料/家长控制限制 |
| 点击快捷发送仍打开 Span | 无障碍服务是否显示“已开启”；关闭后重新开启一次；确认安装的是最新 APK |
| 亮屏正常，锁屏数分钟后失效 | 电池设为“不限制”；允许后台活动；不要使用超级省电模式 |
| 重启后失效 | 开启自启动/应用启动；确认 Span 未被加入休眠、深度休眠或冻结列表 |
| 没有常驻通知 | 允许 Span 通知；确认通知频道“Span 剪贴板同步”没有被关闭 |
| 同一 Wi-Fi 仍找不到 PC | 关闭访客网络/AP 隔离；确认 VPN 没有接管局域网；PC 防火墙放行 Span |
| 系统清理后仍频繁失效 | 在最近任务中锁定 Span；这是补充措施，不能代替无障碍和电池设置 |

## 系统差异说明

菜单名称会随系统版本、地区和机型变化。找不到某一项时，优先使用系统设置顶部搜索框搜索：`无障碍`、`Span`、`自启动`、`应用启动`、`电池优化`、`后台耗电`或`休眠应用`。

Android 官方也说明无障碍入口和名称可能因设备而异，电池优化豁免位于系统电池设置中：

- [Android 无障碍功能入口](https://support.google.com/accessibility/android/answer/16323943)
- [Android Doze 与电池优化豁免](https://developer.android.com/training/monitoring-device-state/doze-standby)
- [Android 侧载应用的受限设置](https://support.google.com/android/answer/12623953)
